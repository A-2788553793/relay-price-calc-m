# relay-price-calc-m

**relay-price-calc-m** 是基于 [A-2788553793/relay-price-calc](https://github.com/A-2788553793/relay-price-calc) 的离线 Android 版，使用 Rust + Slint 开发，用于快速横向对比两个 AI 中转站的价格高低。

---

## 核心功能

- **双模型实时对比**：支持填入两组模型的「输入、输出、缓存写入、缓存读取」单价（每百万 token）及「平均缓存率」。
- **即时分析**：输入数值即时计算价格系数，排名并标出最便宜的一方，自动计算节省比例。
- **灵活输入与容错**：支持自定义模型名，解析全角数字、中文句号、科学计数法及末尾 `%`；非法输入（负数、超 `100%`、数值溢出）会标红提示，不影响整体计算。
- **即时存储与清空**：支持单模型「清除此项」与全部清空，改动自动原子保存到本机配置，彻底离线，不申请任何联网或存储权限。
- **外观定制**：支持深色 / 浅色主题切换，`12-20` 字号缩放。

---

## 计算公式

```text
未命中 = 1 − 缓存率(%) / 100
价格系数 = (输入 + 输出) × 未命中 + (缓存读取 + 缓存写入) × (缓存率 / 100)
```

> **示例**：输入 `3`、输出 `15`、缓存写入 `3.75`、缓存读取 `0.3`、缓存率 `80%`
> (3 + 15) × 0.2 + (0.3 + 3.75) × 0.8 = 3.6 + 3.24 = **6.84**

## 下载与运行

- **直接使用**：前往 [GitHub Releases](https://github.com/A-2788553793/relay-price-calc-m/releases) 下载 `v0.2.2` 的 APK 安装包，在 Android 8.0+ (arm64) 设备上直接安装即可。
- **自定义构建**：通过 GitHub Actions 自动化触发云端构建（参考 [GitHub Actions Android APK](https://github.com/A-2788553793/relay-price-calc-m/actions)）。

> **提醒**：CI 产生的测试签名安装包，每次构建后通常无法覆盖安装旧版本，需先卸载旧版再安装（**卸载将清除本地配置**）。
